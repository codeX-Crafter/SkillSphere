# 🚀 SkillSphere

SkillSphere is a MERN-based learning hub designed for engineering students. It provides **curated roadmaps, resources, and domain-wise learning paths** across Web Development, DSA, UI/UX, AI/ML, AR/VR, and more — all in one clean, personalized platform.

## ✨ Features
- Domain-wise curated roadmaps  
- Resource lists (videos, articles, cheatsheets)  
- Simple, clean, responsive UI  
- Easy navigation with category filters  
- Built as part of my full-stack MERN learning journey  

## 🧰 Tech Stack
**Frontend:** React, CSS  
### Future Scope-
**Backend:** Node.js, Express  
**Database:** MongoDB  

## 📌 Purpose
SkillSphere helps students start and grow in any tech domain with structured guidance and handpicked learning paths.
